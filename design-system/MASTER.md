# Champs School Visual Identity

## Strategy

Champs School should feel trustworthy before it feels playful. Parents need safety and clarity, students need progress and encouragement, and staff need calm operational density. The identity uses a scholarly modern direction: paper-like surfaces, deep academic navy, growth green, and a warm gold signal for action and achievement.

## Color Psychology

- Primary Navy `#102A43`: trust, authority, focus. Use for hero headlines, dashboard shell, key navigation, and serious administrative surfaces.
- Growth Green `#2F7D69`: learning progress, wellbeing, stability. Use for success states, charts, course progression, and secondary highlights.
- Gold `#D89B2B`: achievement, reward, energy. Use sparingly for primary CTAs, active indicators, badges, and celebratory moments.
- Paper `#F7F1E5`: warmth and approachability. Use for page backgrounds so the school does not feel like a cold SaaS tool.
- Ink `#172A3A`: readable long-form text and data labels.

## Usage Rules

- One primary CTA per viewport; gold is reserved for that action.
- Use lucide outline icons only. No emoji as interface icons.
- Cards use 8px radius, clear borders, and one shadow scale.
- Dashboard screens favor density, while landing screens use broader rhythm and stronger storytelling.
- Avoid random emerald/amber/rose gradients. All colors should map back to trust, progress, or achievement.
- Mobile touch targets stay at least 44px high.
- Motion should clarify transitions and hover states, not decorate every element.
